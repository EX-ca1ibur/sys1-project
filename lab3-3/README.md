## 验证思路

课程框架里的判题器用 C++ 写一份参考实现，由 Verilator 把随机激励同时喂给 HDL 和 C++ 模型，逐拍比对输出。相比硬编码测试向量，随机化 + 参考模型能覆盖进位链长度、符号位、全 1 输入等更多边界情况。

> 运行需要课程框架提供的 testbench、约束和 `Makefile`，做法见[根目录 README](..)。
