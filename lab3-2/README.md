# lab3-2 · 参数化计数器与数码管计数显示

实现可配进制、可配初值的计数器，并把计数值转换成数码管能显示的数字。

## 提交代码

| 文件 | 说明 |
| --- | --- |
| `submit/Cnt.sv` | 计数器，参数 `BASE = 10`（模）、`INITIAL = 0`（初值） |
| `submit/Cnt2num.sv` | 数值转换模块，参数 `BASE = 24`、`INITIAL = 16` |

## 设计要点

- **参数化进制**：`BASE` 决定计数上限，同一个模块可复用于时钟、分频计数等场景。
- **可配初值**：`INITIAL` 让计数器从任意值起步，方便时钟类应用（例如从 16 点开始的 24 小时制）。
- **使能控制**：`en` 为高时计数，便于级联成时/分两级计数器。
