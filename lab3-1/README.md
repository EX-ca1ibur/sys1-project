# lab3-1 · 序列检测有限状态机

用四状态状态机检测输入序列中是否出现**连续三个 1**。

## 提交代码

| 文件 | 说明 |
| --- | --- |
| `submit/FSM.sv` | 状态机实现（现态/次态分离的三段式写法） |

## 状态设计

| 状态 | 编码 | 含义 |
| --- | --- | --- |
| `S0` | `2'b00` | 尚未收到连续的 1 |
| `S1` | `2'b01` | 已收到 1 个连续的 1 |
| `S2` | `2'b10` | 已收到 2 个连续的 1 |
| `S3` | `2'b11` | 已检测到 3 个连续的 1，自锁 |

转移规则：`a=1` 前进一态；`a=0,b=0` 停留；`a=0,b=1` 序列被打断回 `S0`；进入 `S3` 后保持。复位低有效（`rstn`），异步复位到 `S0`。
