# lab1-2 · 32 位多路选择器与七段数码管译码

把 1 位选择器扩展到 32 位数据通路，并实现七段数码管的段码译码，为后续实验打下「数据宽度」和「显示」两块基础。

## 提交代码

| 文件 | 说明 |
| --- | --- |
| `submit/Mux4T1_32.v` | 4 选 1 多路选择器，数据位宽 32 bit |
| `submit/SegDecoder.v` | 七段数码管译码器（数值 → 段码） |

## 实现要点

- `Mux4T1_32` 用 `sel[1:0]` 在四路 32 位输入间选择，注意位宽声明和 `case` 的完备性。
- `SegDecoder` 把输入数值映射成 `a..g` 七段控制信号，实际板卡上要考虑共阳/共阴极性。

> 运行需要课程框架提供的 testbench、约束和 `Makefile`，做法见[根目录 README](..)。
