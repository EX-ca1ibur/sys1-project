# lab4-2 · 串口通信（UART 回环，bonus）

在 FPGA 上跑通异步串口：把收到的字节原样发回去，并用上位机串口助手验证。

## 提交代码

| 文件 | 说明 |
| --- | --- |
| `submit/UartLoop.sv` | UART 回环顶层：接收 → 发送，与课程框架的 `UartUnit` 配合完成回环 |

## 实现要点

- **回环结构**：`async_receiver` 检测起始位、按波特率中点采样、校验停止位；`async_transmitter` 按波特率移位输出。两者对接即构成 echo。
- **采样时机**：接收端必须在位时间内多次采样并做多数表决（抗毛刺），否则线上轻微抖动就会误判数据位。
- **跨时钟域**：串口速率与系统时钟无关，起始位下降沿要经过同步与去抖才可靠。
