# lab2-1 · 加法器与加减法器

实现基本算术单元，理解进位链、位宽扩展，以及「加/减复用」的硬件思维。

## 提交代码

| 文件 | 说明 |
| --- | --- |
| `submit/adder.v` | 单个全加器 / 基础加法单元 |
| `submit/adders.v` | 多级级联的加法器 |
| `submit/add_subs.v` | 加减法器（由 `sub` 控制，复用同一条加法通路） |

## 实现思路

减法用「取反加一」实现：`b ^ {n{sub}}` 再加进位输入 `sub`。于是 `sub=0` 是加法、`sub=1` 是减法，符号/溢出判断也从这条通路导出。
